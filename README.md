# Kedai Kersa Website ☕

Website katalog dan profil resmi untuk **Kedai Kersa Purwokerto** — ruang santai dan nugas nyaman dekat kampus Unsoed.

---

## 🚀 Cara Menjalankan

Website ini menggunakan HTML, CSS, dan JavaScript murni (tanpa perlu install library atau backend):

1. **Buka langsung di browser:**
   Cukup klik dua kali (*double click*) file `index.html`.
2. Atau jika menggunakan Visual Studio Code, klik kanan `index.html` dan pilih **Open with Live Server**.

## 📁 Struktur File

- **`index.html`** : Kerangka halaman website.
- **`style.css`** : Desain gaya visual, warna, responsif mobile, dan navbar sticky.
- **`data.js`** : **Pusat data konten yang mudah diedit (menu, harga, jam, kontak, dsb).**
- **`main.js`** : Logika interaktif (menu navigasi, scroll navbar, dan render data).
- **`README.md`** : Panduan penggunaan dan cara edit website.
